# Subspace Lead Generation Platform

## Features

- Discover similar companies using Ocean.io
- Find decision makers using Prospeo
- Verify and enrich contacts
- Email outreach using Brevo
- React dashboard with analytics

## Tech Stack

Frontend:
- React
- Vite

Backend:
- Node.js
- Vercel Functions

Integrations:
- Ocean.io
- Prospeo
- Brevo

## Installation

### Backend

cd backend
npm install

### Frontend

cd frontend
npm install

### Run

Backend:
vercel dev

Frontend:
npm run dev
